# TDnet 利用条件の公式確認

確認日: 2026-11-05
注意: これは公式ページの記載を整理した調査メモであり、法的助言ではありません。確認できなかった点は「不明」と書き、許可扱いにはしていません。

## 1. 結論の早見表

| 利用形態 | 判定 | 根拠の要点 |
|---|---|---|
| 個人用の非公開(自分だけが見る) | 不明(明確な許可は確認できず) | 閲覧サービスは「無断で転用、複製又は販売等」を禁止。ただし私的利用の可否を明記した文言は見つからず。加えてrobots.txtは全面Disallow、JPX本体は高頻度の自動取得を「ご遠慮」 |
| 公開サイトに要約・数値を載せる | 確認できない(許諾が必要な可能性が高い) | 「二次利用及び再配信はできません」(許諾がある場合を除く)。要約・抽出データが例外とは書かれていない |
| PDF原文へのリンクのみ載せる | 不明(禁止の記載もないが、許可の記載もない) | リンクについての規定は「他サイトから当サイトへのリンク」の項のみで、JPX本体サイト向け。TDnet閲覧サービス(release.tdnet.info)固有のリンク規定は見つからず |

「許されると確認できた」ものは1つもありません。

## 3. (b) 有料サービスと無料閲覧の線引き

URL: https://www.jpx.co.jp/markets/paid-info-listing/tdnet/index.html (2026/07/06更新) および https://www.jpx.co.jp/markets/paid-info-listing/tdnet/02.html (TDnet API、2026/06/29更新)。確認日 2026-11-05。

- 有料は4種類: TDnetDBS(月額33,400円〜)、TDnetサーバ型(初期費用200,000円ほか)、TDnet API、TDnet on Snowflake。
- TDnet API(JPX総研): 基本料7万円(税抜)に、取得件数に応じたAPI情報料(300件以下は0円、以降段階的に加算)。過去5年分を取得可能。
- 原文: 「TDnet APIサービスから取得した情報は、第三者に再配信することが可能です。」(「主な利用方法」欄)
- 線引き(公式ページから読み取れる範囲): 無料は直近31日分の閲覧のみ。プログラムによる取得・再配信・長期データは有料契約が前提の作りです。「無料閲覧の自動取得は禁止」と明言した一文は確認できませんでしたが、2-1・2-2の「二次利用及び再配信はできません(許諾がある場合を除く)」と合わせると、再配信を伴う用途の正規ルートは有料契約と読めます(これは私の読み取りであり、公式の明言ではありません)。
- 契約約款(TDnet API サービス利用約款, TermsTDAPIJ.pdf)は取得しましたが、PDFの文字が抽出できず条文は未確認です(不明)。約款上の再配信の条件・範囲(要約や加工データの扱い、表示義務など)は、必要なら JPX総研 クライアントサービス部(api-service@jpx.co.jp)への確認が要ります。
- 個人の小規模利用向けの割安・無料プランは確認できませんでした(不明)。

## 4. (c) 開示情報そのものの著作権・二次利用

- 閲覧サービスの内容は「著作物として著作権法により保護」と明記(2-2)。JPXサイトでは権利はJPX各社に帰属と明記(2-1)。
- 開示資料の元の作成者は各上場会社で、会社側の権利・許諾の扱いについてTDnet公式ページに記載は見つかりませんでした(不明)。
- 決算数値などの事実情報そのものの扱いを、公式ページは区別して書いていません(不明)。「事実は著作物でない」といった一般論は公式根拠ではないため、ここでは許可の根拠にしていません。

## 5. (d) 非公式API webapi.yanoshin.jp

URL: https://webapi.yanoshin.jp/tdnet/ 、https://webapi.yanoshin.jp/llms.txt (確認日 2026-11-05)

- 位置づけ: 「TDnet WEB-API（非公式）by Yanoshin」。JPXの公式サービスではありません。
- 原文(ご注意): 「当サービスはインターネットを利用した情報収集、分析を目的としたものです。」「当サービスはインデックス情報を提供するものであり、提供元サーバへの書類URLリンクを提供しております。書類データは提供元のサイトを必ずご確認ください。」「投資に関しての最終判断は必ず個々の責任にてお願いいたします。」
- 利用規約ページ・商用/再配布可否・レート制限の明文は見つかりませんでした(不明)。
- 重要: この非公式APIが元データをTDnetから取得していること(「数分間隔で東証のデータと同期」)自体について、JPXの許諾を得ているかは確認できません(不明)。非公式APIを経由しても、元データに対するJPX側の条件(2-1, 2-2)を回避できるとは確認できません。
- robots.txtはGooglebotにxml/json/rss/atomを禁止、その他は許可。

## 6. (e) 結論

- 個人用の非公開: 不明。禁止が明記されているのは「無断で転用、複製又は販売」と「二次利用・再配信」で、個人が自分で見るだけの用途が許されるとは書かれていません。ただし機械的な取得はrobots.txtで拒否されており、少なくとも「確認できた許可」はありません。
- 公開サイトに要約・数値を載せる: 許可は確認できません。「複製」「二次利用」「再配信」を許諾なしでは禁じる記載があり、要約・数値の抽出が例外とは書かれていません。公開するなら、JPX総研のAPI契約などで許諾を得るか、事前問い合わせが必要です。
- PDF原文へのリンクのみ: 禁止の記載も許可の記載も見つかりませんでした(不明)。リンクだけなら複製・再配信にあたらない可能性はありますが、公式にそう書いてあるわけではありません。なお、開示後31日を過ぎると閲覧サービス側のPDFは見られなくなるため、リンク切れの問題もあります。

## 7. 公開サイトでの対応案(安全側の順)

1. 公開しない(個人用・非公開に留める)。最も安全。ただし2-3のとおり自動取得自体は歓迎されていない点は残ります。
2. 公開するなら、タイトル・会社名・開示日・PDF原文へのリンクのみに絞る(要約・数値は載せない)。それでも「不明」なので、JPXへの問い合わせ(JPXサイトの「お問合せ」)で確認するのが望ましい。
3. 要約・数値を載せたい場合は、JPX総研のTDnet API契約(基本料7万円/月〜、第三者への再配信可と記載)を検討するか、約款の条文を取り寄せて確認する。
4. どの案でも、出典(東京証券取引所 適時開示情報閲覧サービス)と「原文は必ず公式サイトで確認」「正確性は保証しない」の注記を出す。ただし注記は許可の代わりにはなりません。
5. 取得頻度は最小限(1日数回以内)にし、負荷をかけない。
