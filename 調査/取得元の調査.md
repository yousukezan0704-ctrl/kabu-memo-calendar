# 取得元の調査（2026-11-03 実施）

方法: 公式ページを読み取り専用で取得（1秒以上あけて）。ログイン・登録・APIキー取得はしていません。
「確認できず」は確認済みとして扱っていません。法律の専門判断ではなく、規約の文言に照らした整理です。

## 結論（先に）
1. 決算発表予定日を、規約上そのまま公開サイトで使える無料の一括取得元は**見つからなかった**。J-QuantsもJPXの予定日データが元で、無料版は「12週間前〜」の過去分しか出ず、未来の予定日は取れない。
2. 引け後の日足・出来高の無料自動取得で、公開Webに載せてよいものは**確認できず**。J-Quants無料版は12週間遅れ・個人の私的利用のみ・再配布不可で、公開サイトには不可。
3. TDnet自動収集：JPXの公式な許諾は有料のTDnet API。無料の閲覧サービスと、やのしんWebAPIには「自動収集してよい」とも「いけない」とも書かれていない。
4. 唯一、規約が明確に許しているのは **EDINET（公共データ利用規約PDL1.0、API利用は可、出典表示が必要）**。ただし決算短信・業績修正は対象外。

## 補足：時刻について
TDnet一覧には開示時刻があり、決算短信の発表時刻は発表後に確定で分かる（既に取り込み済みの情報）。発表**前**の予定日・時刻は、会社の「決算発表日のお知らせ」等に載ることがあり、現行の抽出（書いてあるときだけ採用）が最も安全。

## 推奨案
1. **決算発表予定日**: 自動の一括取得は断念。(a) TDnetで拾えたお知らせから会社公表の日付だけ抽出（現行どおり）、(b) 注目銘柄は手入力、(c) 画面にJPX公式一覧へのリンク。J-Quantsの予定日は使わない。
2. **日足・出来高**: 現行どおり株価CSV取込（端末内のみ）。J-Quants無料は12週間遅れで引け後の用途に不向き。将来、有料プランを自分で契約する場合も「自分の端末内だけ」で使い、公開リポジトリ・公開サイトには出さない。
3. **TDnet**: 現状の画面表示（許諾未確認）を維持。確実にしたいなら、やのしん運営者へ「GitHub Actionsで収集し、公開サイトに表題・リンク・抽出結果を表示してよいか」を問い合わせる。回答が得られるまで本文の再配布はしない（リンクと抽出した事実のみ）。
4. **EDINET**: 設備投資計画などの補完として接続を検討（出典表記つき）。
